# 智云优选 - AI 电商在线销售系统（期中作业1）

## 站点说明
一个纯静态电商演示网站，包含：商城首页（商品展示 / 搜索 / 购物车）、管理员登录、后台商品管理。

## 页面结构
- `index.html` —— 商城首页（商品展示、搜索、加入购物车、模拟结算）
- `login.html` —— 管理员登录页
- `admin.html` —— 后台管理页（添加 / 删除商品）
- `style.css` —— 统一样式

## 技术说明
- 纯前端实现（HTML + CSS + JavaScript），无后端
- 商品数据与购物车使用浏览器 localStorage 本地存储
- 已发布至 GitHub Pages 外网访问
